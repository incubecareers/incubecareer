## 2. CORE WEB VITALS + MOBILE-FIRST

**Google indexes mobile version first**
- Site must load fast (LCP under 2.5s)
- Fully usable on mobile
- Most course-seekers browse on phones

**Actions**:
- Optimize images (WebP format, lazy loading)
- Minimize JavaScript bundles
- Use Next.js Image component
- Implement proper caching

---

## 3. SCHEMA MARKUP

### Course Schema
Add `Course` schema with:
- `hasCourseInstance`
- `provider` information
- Unlocks rich results (star ratings, price, duration)

### Organization Schema
Add on homepage:
- Company info
- Contact details
- Social profiles
- Logo

**Benefit**: Rich results directly in Google search

---

## 4. STRUCTURED URL + SITEMAP

### Clean URLs
- `/courses/hr-analytics-placement`
- `/courses/business-analyst-certification`
- No query strings or IDs in public URLs

### XML Sitemap
- Submit to Google Search Console
- Update automatically with new courses
- Clean internal linking from homepage to every program

---

## 5. LOCAL SEO (Google Business Profile)

**Highest ROI for Local Training Institute**

Actions:
- Claim Google Business Profile
- Category: "Training Centre" or "Educational Consultant"
- Add business hours
- Upload photos (classrooms, team, students)
- Collect real reviews from students
- Post updates regularly

**Bangalore-based location = local search advantage**
